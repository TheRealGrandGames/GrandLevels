How to Install Levels

1

Make sure you have Baldi's Basics Plus with the Level Studio Mod installed.

2

Click Download Level File on any level card on this website.

3

Move the downloaded file into your custom levels folder, usually located at:
.../BaldiPlus/Mods/LevelStudio/CustomLevels/

4

Launch Baldi's Basics Plus, open Level Studio, and select your custom level from the custom levels list!
